# Calibration-free discrimination of unresolved sources with symmetric multiphoton measurements

Code, numerical results, pre-registration records and manuscript for the paper of the same name
(draft for *Physical Review A*). The authors are P. B. Kadam, P. S. Gaikwad, S. S. Raut and T. U. Shitole,
Department of Artificial Intelligence and Data Science, AISSMS Institute of Information Technology, Pune, India.

## The result in brief

Deciding whether an unresolved source is one star or a close binary can be done at the quantum limit by sorting
photons into Hermite-Gauss modes. This works only if the sorter is centered on the source.

When the pointing is unknown and must be learned from photons:

- **Measure-first learners** stay background-limited. They centroid by direct imaging, then sort modes or use any
  single-photon receiver we optimized. They keep only a separation-independent fraction of the known-pointing
  quantum exponent:

  | Calibration photons per target photon | Fraction kept |
  |---|---|
  | 0 | 17-20 % |
  | 1 | 33 % |
  | 100 | 63 % |
  | 1000 | 69 % |

- **Symmetric projection** of k stored target photons has zero background for every pointing and any static
  crosstalk.
  - It needs no calibration and reaches (k-1)/k of the limit.
  - Groups of four beat 1000 calibration photons per target photon.
  - The gain in error exponent is 1.6 to 5.7.
- **With one target photon**, joint learning keeps a constant 18 % advantage over measure-first learning, through
  an interference port that is dark for every pointing.
- **Translation invariance alone** gains at most 1 % over the two-photon Hong-Ou-Mandel test.

## Layout

| Path | Content |
|---|---|
| `research/space/qx3e_exponents.py` | many-photon error exponents: measure-first learners vs symmetric projection (Secs. III-IV) |
| `research/space/qx3_learn_then_classify.py` | single-photon learn-then-classify, exact joint optimum (Sec. V) |
| `research/space/qx2_invariant_pairs.py` | translation- vs permutation-invariant two-photon measurements (Sec. VI) |
| `research/space/x_suite.py`, `s01_exponents.py` | shared state constructions; `x_suite.py X5` gives the two-photon memory tolerances (Sec. VII) |
| `research/qk/util.py` | run metadata and I/O helpers |
| `results/` | the JSON results behind every number in the paper |
| `paper/pra_calibration_free/` | REVTeX manuscript; `gen_tables.py` and `gen_figures.py` rebuild every table and figure from `results/` |
| `docs/PREREGISTRATION.md` | pre-registration, written before each experiment's code. Addenda H and I cover this paper |
| `docs/RESULTS.md` | verdicts for every pre-registered prediction (sections 14-16 for this paper), including refuted ones and corrections |
| `docs/CLAIMS.md`, `docs/novelty/` | claim ledger and literature novelty checks |

`docs/PREREGISTRATION.md` and `docs/RESULTS.md` are the complete research log, so their earlier sections refer to
experiments whose code is not part of this repository.

`results/qx3e/qx3e_run1_halfdomain.json` is a faulty run, kept on purpose. Its worst-case search was one-sided; the
fault was fixed before any verdict, as described in Appendix D of the paper.

## Reproducing

Python 3.13 with the pinned packages in `requirements.txt`.

```bash
pip install -r requirements.txt
python research/space/qx3e_exponents.py        # ~20 min, 5 processes -> results/qx3e/qx3e.json
python research/space/qx3_learn_then_classify.py   # ~1 min -> results/qx3/qx3.json
python research/space/qx2_invariant_pairs.py   # ~10 min -> results/qx2/qx2.json
python research/space/x_suite.py X5            # -> results/x_suite/X5.json
python paper/pra_calibration_free/gen_tables.py
python paper/pra_calibration_free/gen_figures.py
cd paper/pra_calibration_free && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Use of AI tools

This work made substantive use of Claude Opus 5.5 (Anthropic, `claude-opus-5-5`) through Claude Code, with
Claude Sonnet 5.5 sub-agents for literature searches.

- **What the AI did:** derivations, simulation code, numerical experiments, literature searches and drafting.
- **What the authors did:** P. B. Kadam directed all of the work and verified and checked all of the calculations
  by hand.
- **Controls:** every prediction was committed to the pre-registration file before the code that tested it, and
  every table and figure is regenerated by script from `results/`.
